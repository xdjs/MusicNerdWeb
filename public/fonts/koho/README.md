# KoHo — declared Music Nerd brand typography

Unmodified static Regular/Bold from the official Google Fonts repository:
https://github.com/google/fonts/tree/main/ofl/koho

Copyright 2018 The KoHo Project Authors (https://github.com/cadsondemak/Koho).
Complete SIL Open Font License 1.1 retained as OFL.txt.

Regular: 96,176 bytes. Bold: 94,068 bytes. Total: 190,244 bytes.
Exact SHA256 checks are in scripts/artist-share/verifyOfflineRender.cjs.

The site declares KoHo in globals.css but does not load it. These server-rendered
cards load it locally, with Inter as glyph fallback. Homepage rendering is unchanged.
