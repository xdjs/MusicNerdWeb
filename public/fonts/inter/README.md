# Inter 4.1 — artist share image fonts

Unmodified official static TrueType files from:
https://github.com/rsms/inter/releases/tag/v4.1

Archive: https://github.com/rsms/inter/releases/download/v4.1/Inter-4.1.zip
Paths: `extras/ttf/Inter-Regular.ttf`, `extras/ttf/Inter-Bold.ttf`.
The archive's complete `LICENSE.txt` is retained here (SIL Open Font License 1.1).
Official project: https://rsms.me/inter/

The server embeds these fonts locally for reproducible offline OG rendering.
Regular: 411,640 bytes; Bold: 420,428 bytes; total: 832,068 bytes.
No variable-font conversion, font modification or runtime download is involved.
Coverage and exact hashes are checked by `scripts/artist-share/verifyOfflineRender.cjs`.
The homepage continues using the device's installed system font; these are a
reviewable Inter alternative for cards, not a claim of an exact homepage match.
