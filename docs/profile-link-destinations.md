# Profile link destinations

2026-10-08 correction requested by Pete: Links contains artist destinations, not
individual songs or albums. URL classification is authoritative even if a release
was saved with type website/profile. Release sources remain stored and reviewable
in Lore; this change does not manufacture Latest entries or erase source history.

Approved, identity-permitted music artist destinations saved as sources appear in
the same platform-icon grid as direct artist fields. Apple Music and Beatport use
local icons from Simple Icons (CC0). Source-backed destinations retain their
existing source approval/removal controls in edit mode. They do not call the
direct artist-column deletion API or enter its saved reorder payload.

Official websites retain their labeled website link treatment. Pending and
identity-conflicting source profiles remain excluded from the public grid.
