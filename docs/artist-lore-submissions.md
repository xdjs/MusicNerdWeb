# Lore URL suggestions

The artist page has two link flows. **Add a link** submits a supported profile-service URL through the UGC queue, where ordinary accounts wait for admin review. **Suggest a Lore source** accepts a public article, interview, review, or other source URL from a signed-in account. It creates a pending `artist_vault_sources` row; the source stays off the public Lore carousel until an approved claimant or admin approves it in edit mode. For a claimed profile, the confirmation says it is pending artist review. For an unclaimed profile such as Bike Lane, it explains that an admin can review the source until the artist claims it.

An artist owner or admin can enter Lore edit mode from the section itself, add more source URLs, and approve or reject pending sources. An admin can edit any artist profile, subject to the account's `users.is_admin` flag. Duplicate source URLs return an already-suggested message, without adding a second row. The API validates public HTTP(S) URLs server-side and uses the existing `/api` request rate limit. Visitor submissions and approval save the URL without fetching it. Approved URL-only suggestions appear with a domain-based title; richer extraction requires a separate durable job with network destination checks.
