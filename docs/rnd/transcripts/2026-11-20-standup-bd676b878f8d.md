## Summary (Granola)

**Board progress**

- Privy authentication is added, its environment variables are set, and preview testing is done.
- The first PRs are up but not shipped. A second pass moves the API endpoints into the API codebase instead of the Board repo.
- The board is also driving deeper work on the MCP server.

**MCP: REST vs. native tooling**

- The core question was whether agents should use REST endpoints or MCP tools.
  - REST: agents can read the docs and call the endpoints directly.
  - MCP: the server returns a specific list of tools, which is more agent-first and avoids drift between the docs and the endpoints.
- The existing Music Nerd MCP has basic token auth: a token is generated in the admin dashboard.
- Claude requires OAuth, so OAuth is being built into the MCP.
  - The connect flow: add the MCP URL to the Claude Duet and click Connect. A Music Nerd page opens, the user signs in with Privy, and an OAuth token is returned.
- Plan: build the OAuth path alongside the old one, then remove the token path, since nothing uses it.

**Board as the engineering hub**

- The vision is that the board replaces engineering communication: the Discord Music Nerd channel, GitHub Projects and GitHub Issues.
  - Pull requests are the only GitHub artifact that stays.
  - Code review, task management and agent communication all move to the board.
- Board demo:
  - In the code-review channel, the issue, its PRs, preview screenshots and test notes sit in one thread.
  - The agent runs the threads itself. Emoji reactions (for example a rocket) signal shipping.
  - Tasks aren't set up yet but are the natural next step.
- Agreed purpose of each channel:
  - Discord: public signal that Music Nerd is alive and active, open to the community.
  - iMessage: the inner-circle water cooler and private team admin.
  - Board: the open-office plan for humans and agents, focused on engineering.
  - Telegram: can be shut down. It was created only to include Sweetman before he joined the iMessage thread.
- The experiment goes all the way in: ignore Discord for now and reassess on December 10.
  - To unlock it, Privy auth gets finished today, then Carl and Pete are onboarded.
