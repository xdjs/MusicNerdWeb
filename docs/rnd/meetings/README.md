## Add the next record

Use [_template.md](_template.md), preserving the August 20 style: short context, topic sections,
decisions and reasoning, open threads and next actions. Use `YYYY-MM-DD.md` for the main team
record, adding a descriptive suffix for another session that day. Attribute actual speakers,
not everyone on an invitation. For artist tests, omit participant details unless public
attribution has been agreed; deeper findings belong in `research/`.

Read source notes or a transcript before recording an outcome. An agenda is evidence of planned
topics only. If source material is missing, add the gap to this index rather than fabricating
minutes. Record what was not reached only when the source establishes it. Update the decision
index and commitments with evidence, keeping a meeting's original intent separate from later
implementation or release status.
