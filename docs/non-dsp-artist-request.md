# Non-DSP artist requests (#1312)

Pete confirmed the destination mailbox on September 21. The Add Artist dialog offers “Don’t release on Spotify or Deezer?” below the normal DSP form. Expanding it collects an optional artist name and public music/profile links, then opens a prefilled email for the user to review and send. A copyable request and visible destination support users without a configured mail app. This requests team review; it does not create a profile, verify ownership, write to the database or loosen DSP validation.
